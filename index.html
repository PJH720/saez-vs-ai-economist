The AI Economist

Improving Equality and Productivity with AI-Driven Tax Policies

Zheng, Trott, Srinivasa, Naik, Gruesbeck, Parkes, Socher (Salesforce Research + Harvard, 2020)
발표: 박재현 · AI@Sogang RL 스터디 · 2026-08-13

우리는 지금 어디에 있나

  • CS285 진도: Lecture 1~3 (Intro, Behavioral Cloning, PyTorch) 완료 — Policy Gradient/PPO는 아직
  • 오늘 다룰 논문은 새로운 RL 알고리즘을 만드는 논문이 아니라, 기존 RL 기술(MDP, PPO)을 가져와 조세 정책 문제에 적용한 응용 논문입니다.
  • 그래서 오늘은 딱 필요한 만큼의 RL 어휘 → 논문 본론 → 경제학적 비판 순으로 진행
Act I — The Sandbox

강화학습의 기본 어휘 3개

  • State (상태) s: 에이전트가 관측하는 환경의 현재 모습
  • Action (행동) a: 에이전트가 선택할 수 있는 행동
  • Reward (보상) r: 행동 후 환경이 주는 피드백 (스칼라 값)
목표: 누적 보상(Σ γᵗrₜ)을 최대화하는 정책(policy) π(a|s)를 학습

RL 알고리즘의 두 전통

Value-based

DQN (Mnih et al., 2013)

"각 행동의 가치(Q값)를 추정하고, 가장 높은 걸 고른다"

Policy-based

PPO (Schulman et al., 2017)

"행동을 선택하는 정책 자체를 직접 학습한다"

Bottom note: 오늘 논문은 전부 Policy-based(PPO)로 학습됨

PPO — 딱 필요한 만큼만

  • 정책 업데이트 보폭이 너무 크면 정책이 붕괴할 위험
  • TRPO(Schulman et al., 2015)는 2차 미분으로 이를 막음 → 연산 비용 큼
  • PPO의 해법: 새 정책이 이전 정책 대비 [0.8배, 1.2배] 범위를 벗어나면 더 이상 보상/페널티를 주지 않는다 (Clipping)
  • 한 줄 요약: "좋은 방향이든 나쁜 방향이든, 한 번에 너무 급격히 바뀌지 않도록 브레이크를 거는 안정적인 알고리즘"
  • 현재 RL 업계 표준이며, RLHF(ChatGPT)의 핵심 엔진

🌟 BRIDGE

동적 최적화(경제학) ↔ 강화학습(RL) 1:1 대응

경제학 (동적 최적화) 강화학습 (RL / MDP)
상태변수 X_t & 선택변수 Y_tState s_t & Action a_t
상태방정식 X_{t+1} & 순편익 π_t전이함수 P(s'|s,a) & 보상 r_t
목적함수 max Σ βᵗ π_t (할인인자 β)목적함수 max E[Σ γᵗ r_t] (할인율 γ)
코스테이트 변수 λ_t (그림자가격)가치함수의 기울기 ∂V/∂s
해밀토니안 H = π + λ·f(X,Y)벨만 방정식 Q(s,a) = r + γV(s')

최적화 조건도 한 줄씩 대응한다

1. 선택변수 조건
∂H/∂Y = 0 ↔ 벨만의 max_a
2. 코스테이트 방정식
∂H/∂X = rλ − λ̇ ↔ 가치함수의 시간적 일관성(TD 업데이트)
3. 상태방정식
Ẋ = F(X) − Y ↔ 환경의 전이(transition)
4. 횡단조건
lim_{t→∞} e^{−rt}λ(t)X(t) = 0 ↔ 종단·경계 조건
⚠️ 해밀토니안(폰트리아긴 최대원리)과 벨만 방정식(동적계획법)은 완전히 같은 것이 아니라, 같은 문제를 연속시간/이산시간에서 각각 푸는 쌍대적 접근입니다.
Act II — Why Simulation?

형평성 vs 생산성 — 풀리지 않는 트레이드오프

세율 ↑ → 재분배로 형평성(Equality) 개선, but 근로의욕 저하로 생산성(Productivity) 하락
정부는 실제 경제에서 세율을 마음대로 실험할 수 없음 (위험 + 데이터 부족)
기존 경제학 모델은 분석 가능하도록 단순화된 가정을 전제 → 현실의 복잡한 상호작용을 놓침

비교 대상이 되는 최적과세이론

  • Mirrlees(1971)에서 출발: 정부는 개인의 생산성을 못 보고 소득만 관찰 가능 (비대칭 정보)
  • Saez (2001): 세율 변화의 효과를 3가지로 분해
    • 기계적 효과 (Mechanical) — 행동 불변 가정 시 세수 증가분
    • 행동 효과 (Behavioral) — 근로의욕 감소로 인한 세수 감소분
    • 후생 효과 (Welfare) — 개인 효용 변화
  • 3가지 합이 0이 되는 지점 = 최적 세율

Saez의 '행동 효과'는 정적 탄력성으로 가정된다

  • Saez 공식은 소득분포 f(z)와 탄력성 e(z)를 입력으로 받는 수식
  • 세율 변화에 대한 사람들의 반응(탄력성)을 고정된 숫자로 놓고 계산
  • 실제로는 조세회피, 소득 시점 조정 같은 동적 전략은 반영 못 함
이 전제 하나가 후반부 비판의 핵심 복선입니다.
Act III-A — 설계와 방법론

경제를 통째로 시뮬레이션한다

  • 서로 다른 기술 수준(skill)을 가진 4명의 에이전트가 2D 공간에서 활동
  • 자원(나무🪵, 돌🪨) 채집(Gather) → 코인💰으로 거래(Trade) → 집🏠 건축(Build)로 소득 창출
  • 정부(Social Planner)는 이 경제를 관찰하며 세율을 조정
Gather → Trade → Build → Income → Tax

두 개의 학습 루프가 동시에 돌아간다

Inner-loop (에이전트)

4명의 노동자 AI가 세후 효용을 극대화

Outer-loop (플래너/정부)

사회 후생 극대화, 7개 구간 소득세율 조정

둘 다 PPO로 학습됨

'정책망 5개'가 아니라, 가중치 공유 구조입니다

에이전트 1, 2, 3, 4
↓
단일 에이전트 정책망 (Shared Weights)
↓
각자의 Local State(위치, skill 등)에 따라 다른 Action 출력
플래너 정책망 1개 별도

총 2개의 정책망만 존재

무엇을 최적화하나

// 0~1, 1이면 완전평등
eq(x) = 1 − gini(x) · N/(N−1)

// 전체 자산(소득) 합
prod(x) = Σxᵢ

// 주 목적함수: 평등과 생산성의 곱
swf = eq × prod
  • 세율은 7개 소득 구간, 구간 경계 고정, 세율만 학습

서로가 서로에게 움직이는 과녁

  • 논문 표현: "플래너가 에이전트의 MDP 자체를 바꾼다"
  • 에이전트 행동 변화 → 최적 세율 변화 → 에이전트 행동 변화 (Non-stationary)
  • 한쪽이 급격히 정책을 바꾸면 전체 시스템 붕괴 → PPO의 클리핑이 이를 방지

그래도 부족하다 — 2가지 추가 장치

1. 2단계 학습 + 세금 커리큘럼

  • Phase 1: 무세금 자유시장에서 에이전트만 먼저 학습
  • Phase 2: 세금 활성화 + 플래너 동시 학습. 최대 허용 한계세율 10%→100% 선형 어닐링

2. 엔트로피 정규화 (A3C 계보)

  • 초반엔 정부가 다양한 세율을 무작위로 탐색, 점진적으로 엔트로피 감소
Act III-B — 결과

AI가 찾은 세율이 경제학 최고 이론보다 낫다

+16%
  • eq × prod 트레이드오프에서 Saez 대비 16% 개선 (시드 10개 평균)
  • 세금은 언제나 자유시장보다 생산성을 낮춘다 — AI도 예외 아님. 다만 생산성 손실이 가장 작으면서 평등은 가장 많이 얻음
  • 도출된 세율 구조: 비단조 (progressive+regressive 혼합)

왜 Saez가 졌는가 ① 기계적 효과

  • Saez 결과는 소득분포 형태에 민감: 로그정규형 → 역진세, 파레토형 → 누진세
  • 이 시뮬레이션의 소득분포는 로그정규형에 가까움 → Saez 공식이 역진적 세율표를 산출
  • 역진세 = 재분배가 약함 = 낮은 평등도

왜 Saez가 졌는가 ② 행동 효과 (하이라이트)

분업이 무너진다 — Saez 세제의 숨은 대가

  • Saez 세제 아래: 고숙련 "buyer-and-builder"가 자원을 직접 채집 늘림 → 저숙련에게서 덜 구매
  • 거래 위축 → 저숙련 에이전트 소득 감소 → 분업(specialization) 해체
  • 분업 해체 → 건축 소득 감소 → 생산성 저하
세율↑ → 고숙련 직접채집↑ → 거래↓ → 저숙련 소득↓ → 분업 해체 → 생산성↓

조세 회피: 소득을 교대로 번다 — Jensen 부등호가 뒤집힌다

  • 상식: 누진세 아래선 소득을 매년 평탄하게 버는 게 절세 (Jensen 부등식)
  • 실제 관측: 에이전트들은 고소득/저소득을 번갈아 버는 전략을 학습
  • 이유: 세율표에 역진 구간이 있어 Jensen 부등호가 뒤집힘
  • 누진세(미 연방): 교대 전략 유리한 구간 0/7
  • 역진세(Saez): 교대 전략 유리한 구간 7/7
Act III-C — 비판적 검토

성과 지표 자체가 하나의 가치판단이다

  • 주 목적함수: swf = eq × prod (곱셈형)
  • 이건 공리주의(Σuᵢ)도, 롤스주의(min uᵢ)도, Atkinson/CES 계열도 아님
  • 곱셈형은 '평등과 생산성이 완전보완재'라는 강한 규범적 가정
  • '16% 개선'은 이 특정 후생함수를 받아들일 때만 성립
Key finding: 후생함수 7종 비교 시 1위가 3종류로 갈림

비교는 공정했나 — Saez 공식에 넣은 입력값의 문제

  • Saez 베이스라인은 일정한(constant) 탄력성을 가정
  • 논문도 인정: '탄력성 추정은 현실 경제에서 매우 비자명(highly non-trivial)하다'
  • 탄력성 e만 0.2→1.5로 바꿔보면: 평균 한계세율 67.5% → 28.6% (38.9%p 폭)
  • AI가 이긴 이유의 일부: 'Saez 공식을 설계 정의역 밖에서 적용했기 때문'일 수 있음

MTurk 인간 실험 결과를 정확히 읽으면

  • 논문 원문(Abstract): '... an AI tax policy provides an equality-productivity trade-off that is similar to the Saez framework...'
  • 형평성-생산성 트레이드오프에서는 대등(competitive)했을 뿐, 이기지 못함
  • 우위는 다른 지표(inverse-income weighted welfare)에서만 나타남
  • 16%라는 숫자는 AI 시뮬레이션 안에서만 나온 숫자 — 인간 실험에서는 재현되지 않음
이걸 정확히 말하는 게 오히려 발표의 신뢰도를 높입니다.
Act IV — Conclusion

오늘의 핵심 요약

  • 1. 경제학의 정적 수식(Saez) → RL 기반 동적 시뮬레이션으로 대체 가능성을 보여준 첫 사례
  • 2. 방법론 핵심: PPO + 세금 커리큘럼 + 엔트로피 정규화로 다중 에이전트 학습 불안정성 해결
  • 3. Saez의 패배는 '이론이 틀려서'만이 아니라 '정적 가정 + 좁은 적용 범위'의 결과일 수 있음
  • 4. 경제학의 동적 최적화 전통(NDPF)과 RL의 MDP는 실은 같은 문제의 두 접근
  • 5. "학생이 신경망을 익히고 → 알고리즘이 아케이드 게임을 정복하고 → 인공사회가 조세정책을 최적화한다"
